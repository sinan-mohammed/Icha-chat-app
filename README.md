# 💖 OnlyUs – Private Chat for Couples

OnlyUs is a real-time private chat application designed exclusively for two people.  
No noisy groups. No distractions. Just meaningful conversations ❤️

---

## ✨ About The Project

OnlyUs is a full-stack real-time messaging app built with modern web technologies.  
It provides a secure, minimal, and intimate space for couples to connect.

Whether you're in a long-distance relationship or just value privacy, OnlyUs creates a quiet digital space for your conversations.

---

## 🚀 Features

💌 **Real-Time Messaging**  
Instant chat powered by WebSockets

🔐 **Secure Authentication**  
- Email + OTP Login  
- Google Login  
- JWT-based session management  

👥 **One-to-One Only**  
No group chats. Ever.

❤️ **Couple-Focused Experience**  
- Private conversations  
- Clean & distraction-free UI  

⚡ **Modern UI/UX**  
Smooth loading states & responsive design
